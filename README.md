# DP_AntiCheat

Дизайн античита для DayZ: **серверный авторитарный слой + клиентский сенсор без
нативных инжектов**. Статус — предложение: архитектура, границы доверия и метрики
зафиксированы до первой строчки кода.

- **Сервер** — плагин на [GRAFT](https://github.com/KRdayzmodding/KR_GRAFTED) в
  `DayZServer_x64.exe`: факты, вердикты, агрегация. Игрокам на их машинах не нужно
  ничего.
- **Клиент** — сенсор на чистом Enforce (миссия или подписанный мод), без GRAFT:
  телеметрия и косвенные улики, ничего не вердиктит.

Документ: [`docs/anticheat.md`](docs/anticheat.md)
